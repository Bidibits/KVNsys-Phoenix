**KVNsysServerApp** — the server's dashboard, opened from the KVNsys Server icon on the server PC: turn the server on and off, whether it starts when the PC starts, whether closing the dashboard turns it off too (off unless ticked), who's connected and disconnecting them, and the server password (on or off, and changing it). It controls the server rather than being it, so closing it leaves the server running unless that box is ticked. It needs administrator rights, because Windows only lets administrators turn services on and off; its icons ask for them ("Run as administrator", set by the server's setup), not the program itself, because a program marked to always need them can't start its own window. May use: KVNsysServer, KVNsysUI.
